# 字段说明

本章为系统数据字典：字段名可直接用于策略代码、因子公式、筛选条件与开放接口。所有字段均按交易日截面组织，一个标的每天一行。

## 1. 命名与编码规范

| 对象 | 规范 | 示例 |
| --- | --- | --- |
| 标的代码 | 6 位代码 + 交易所后缀；沪市 `.SH`、深市 `.SZ` | `600519.SH`、`000001.SZ`、`510300.SH` |
| 交易日 | `YYYY-MM-DD` | `2026-11-27` |
| 自定义信号 id | 小写字母/数字/下划线，1–40 位，全局唯一 | `low_touches_ma5` |
| 自定义信号列 | `csg_<id>`；历史迁移信号沿用 `signal_*` | `csg_low_touches_ma5` |
| 盘中信号列 | `csgi_<id>`（日内口径） | `csgi_low_touches_ma5` |
| 自定义因子 id | `uf_` + 小写字母/数字/下划线 | `uf_vol_price_corr` |
| 复合因子 id | `cf_` + 小写字母/数字/下划线 | `cf_multi_momentum` |
| 策略文件 | Python 源码，位于 `data/strategies/custom/`、`data/strategies/ai/` | `my_breakout.py` |

## 2. 单位与口径速查

| 字段族 | 单位 | 易错点 |
| --- | --- | --- |
| 价格类 `open/high/low/close` | 元（前复权） | 不是原始成交价，跨除权事件比较时不可与 `raw_*` 混用 |
| `raw_close` 等 | 元（不复权） | 仅用于涨跌停判定与真实价位展示 |
| `volume` | 手（100 股） | 换算股数需 ×100 |
| `amount` | 元 | 展示为亿元需 ÷1e8 |
| `change_pct` / `momentum_*` / `deviate_*` | 小数 | 0.05 表示 5%，不是 0.05% |
| `turnover_rate` | 百分数 | 3.5 表示 3.5% |
| 回测收益类指标 | 小数 | `total_return=0.35` 表示 35% |
| 回测胜率 `win_rate` | 小数 | 0.62 表示 62% |

## 3. 行情、指标与关联字段

共 57 个字段，按用途分组。以下字段可直接在策略代码、因子 DSL、筛选条件与回测配置中引用。

### 存储列 · 原始行情与状态

| 字段 | 含义 | 口径 / 单位 |
| --- | --- | --- |
| `symbol` | 股票代码 | 形如 600519.SH / 000001.SZ |
| `date` | 交易日期 | 交易日（YYYY-MM-DD） |
| `open` | 前复权开盘价 | 前复权；策略与因子统一使用前复权价 |
| `high` | 前复权最高价 | 前复权 |
| `low` | 前复权最低价 | 前复权 |
| `close` | 前复权收盘价 | 前复权；计算收益、均线的基准价 |
| `volume` | 成交量 | 单位：手（100 股） |
| `amount` | 成交额 | 单位：元 |
| `raw_close` | 原始收盘价(未复权) | 不复权；涨跌停判定使用该列 |
| `raw_high` | 原始最高价(未复权) | 不复权 |
| `raw_low` | 原始最低价(未复权) | 不复权 |
| `turnover_rate` | 换手率 | 单位：百分数（3.5 表示 3.5%），依赖当时流通股本 |
| `consecutive_limit_ups` | 连板数 | 递推状态，按历史连续涨停累计 |
| `consecutive_limit_downs` | 连跌数 | 递推状态，按历史连续跌停累计 |

## 4. 信号字段

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `id` | 信号标识 | 全局唯一，1–40 位小写 |
| `name` | 显示名称 | 界面与告警中的中文名 |
| `kind` | 类型 | `entry` 入场 / `exit` 出场 / `both` 通用 |
| `conditions` | 条件数组 | 每项含 `left`（字段或 `field:xxx`）、`op`（> >= < <= == !=）、`right`（字段/数值）、可选 `leftDays/rightDays`（前移天数） |
| `enabled` | 是否启用 | 停用后不再生成信号列 |
| `timeframe` | 频率 | `daily` 日线 / `intraday` 日内 |
| `min_bars` | 最少样本 | 不足时该标的当日不产出信号 |
| `column` | 输出列名 | 缺省 `csg_<id>`；迁移信号为 `signal_*` |
| `archived` | 是否归档 | 可逆：不展示但仍参与计算 |
| `owner` | 归属账号 | `null` 为共享（内置）定义 |
| `read_only` | 是否只读 | 共享定义在账号模式下只读 |
| `hidden` | 是否已隐藏 | 仅本人视图生效，不影响计算 |

## 5. 因子字段

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `id` | 因子标识 | `uf_` 自定义、`cf_` 复合；内置因子为短名 |
| `label` / `group` | 名称 / 分组 | 界面展示与归类 |
| `kind` | 类型 | `base` 内置 / `virtual` 派生 / `composite` 复合 / `custom` 自定义 |
| `formula` | 公式 | DSL 文本，可复核 |
| `version` | 版本 | 改公式递增，并回到草稿态 |
| `status` | 生命周期 | `draft` / `active` / `watch` / `retired` |
| `direction` | 方向 | `high` 值大看多 / `low` 值小看多 / `none` |
| `unit` | 单位 | 展示与比较口径（如 %、元、倍） |
| `warmup_bars` | 预热天数 | 滚动窗口长度，不足则结果为空 |
| `pit` | 点时数据 | `true` 表示仅使用公告日不晚于当日的财务数据 |
| `asset_types` | 适用资产 | `stock` / `etf` |
| `stability` | 稳定性 | `stable` / `experimental` / `deprecated`（status 的二元投影） |
| `dependencies` | 依赖列 | 公式引用的原始字段 |
| `archived` | 归档 | 不展示但仍参与计算 |
| `owner` / `read_only` | 归属 / 只读 | 共享层定义为只读 |

## 6. 回测与绩效指标

| 字段 | 含义 | 口径 |
| --- | --- | --- |
| `total_return` | 区间总收益 | 期末净值 / 初始资金 − 1，小数 |
| `annual_return` | 年化收益 | 按区间长度年化，小数 |
| `max_drawdown` | 最大回撤 | 净值峰值到谷底的最大跌幅，小数（正数表示幅度） |
| `sharpe` | 夏普比率 | 按逐笔收益标准差年化（×√252） |
| `sortino` | 索提诺比率 | 仅惩罚下行波动，与夏普同基准 |
| `calmar` | Calmar 比率 | 年化收益 / 最大回撤 |
| `win_rate` | 胜率 | 盈利笔数 / 总笔数，小数 |
| `profit_factor` | 盈亏比 | 平均盈利 ÷ 平均亏损（≥1 有效） |
| `n_trades` | 成交笔数 | 完整回合数 |
| `avg_pnl / avg_win / avg_loss` | 平均盈亏 | 逐笔收益率均值，小数 |
| `best / worst / median_pnl` | 单笔极值 | 最好、最差、中位逐笔收益 |
| `avg_holding_days` | 平均持仓天数 | 自然交易日 |
| `mc_maxdd_p50 / p95` | 蒙卡回撤 | 交易序列自助重抽样 1000 次的中位 / 95% 最坏回撤 |
| `final_equity / initial_capital` | 期末净值 / 初始资金 | 元 |
| `avg_exposure / max_exposure` | 平均 / 最大仓位 | 持仓市值占净值比例，小数 |
| `benchmark_return / excess` | 基准收益 / 超额 | 与所选基准比较，小数 |
| `avg_return / median_return` | 信号后平均收益 | 策略信号模式：信号后固定持有期的收益均值/中位 |
| `return_distribution` | 收益分布 | 按分位分箱的计数与占比 |

## 7. 监控规则与通知

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `type` | 规则类型 | 策略 / 个股信号 / 价格涨跌 / 市场异动 / 板块 |
| `scope` | 作用范围 | 指定标的、策略结果或全市场 |
| `conditions` | 条件列表 | 字段、运算符、阈值、前移天数 |
| `logic` | 组合方式 | `AND` 全部成立 / `OR` 任一成立 |
| `cooldown` | 冷却期 | 同一条件重复成立时的最小通知间隔 |
| `severity` | 严重级别 | 决定通知样式与提示音 |
| `enabled` | 启用状态 | 停用后不评估、不通知 |
| `owner_id` | 归属账号 | 触发记录只投递给该账号 |

板块类规则的触发前置条件：有效成分不少于 5 只，且实时行情覆盖率达到 80%。

## 8. 开放接口

| 项目 | 说明 |
| --- | --- |
| 鉴权头 | `Authorization: Bearer tsp_<token>` |
| Token 形式 | `tsp_` 前缀，只在创建时显示一次；服务端仅存 SHA-256 哈希 |
| `read:market` | 标的搜索、日 K、分时、指数、市场快照 |
| 写入类 scope | 按页面划分（策略、监控、数据维护等），创建时按最小权限勾选 |
| 事件流 | SSE 推送任务与行情事件；断线后按事件 id 续订 |
| 返回结构 | JSON；错误统一为 `{"detail": "..."}`，HTTP 状态码语义遵循 REST |
