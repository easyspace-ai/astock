# 访问与登录

## 访问地址

| 项目 | 内容 | 说明 |
| --- | --- | --- |
| 访问地址 | `http://47.119.36.147:3018` | 当前交付实例；如后续绑定域名或启用 HTTPS，以交付确认单为准 |
| 服务端口 | `3018` | 后端与前端同端口提供服务，无需单独访问前端端口 |
| 健康检查 | `GET /health` | 返回 `200` 表示服务正常，可用于监控探活 |
| 登录入口 | `/`（未登录自动跳转登录页） | 邮箱 + 密码登录 |

## 浏览器与终端要求

- 推荐 Chrome / Edge 最新版本；Safari 近期版本可用。不支持 IE。
- 建议分辨率 1440×900 及以上；系统支持深色模式，跟随操作系统设置。
- 图表、K 线、分时均为前端渲染，需要启用 JavaScript 与本地存储。
- 如处于企业内网，需放通到服务端 `3018` 端口的 TCP 访问。

## 账号与角色

| 角色 | 权限范围 |
| --- | --- |
| 超级管理员 | 全部权限，可管理用户、权限组、系统设置与数据维护 |
| 普通管理员 | 按分配的管理权限运营，可维护数据与配置 |
| 编辑者（默认） | 常规使用：策略、因子、回测、监控、分析等业务功能 |

新增账号、重置密码、调整权限组均在「管理后台 → 用户与权限」完成。每个账号的自选、批次、模拟盘、策略池、自定义信号与因子等私有数据相互隔离，行情与指标等共享数据由同一部署共用。

## 登录与会话

- 登录方式：邮箱 + 密码；同一 IP 连续 5 次密码错误锁定 5 分钟。
- 会话保存于 HttpOnly Cookie，有效期 30 天；「退出登录」立即吊销当前会话。
- 已配置邮件服务时，可在登录页使用「忘记密码」自助重置；未配置时由管理员在后台重置。
- 首次登录后请立即修改初始密码，并妥善保管管理员账号。
