本说明书用于交付验收与日常使用：说明系统访问方式、各功能模块的操作口径、使用中的边界与注意事项，以及系统内全部数据字段的含义。阅读顺序建议为「访问与登录 → 系统总览 → 对应模块 → 字段说明」。

文中截图均取自交付的线上实例（真实行情、真实账号权限），网页版可点击任意截图放大查看；PDF 版可放大页面或缩放阅读。

| 序号 | 交付物 | 内容 | 形式 |

::: tip 文档使用约定
文中「页面路径」指浏览器地址栏中的路由（如 `/factors`），可直接拼接在访问地址后打开。所有界面以交付版本实际显示为准；文档与界面不一致时，以系统内「设置 → 系统设置」中的版本信息与页面提示为准。
