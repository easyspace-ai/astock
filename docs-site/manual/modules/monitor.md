# 监控中心与通知

**用途**：管理监控规则、查看触发记录并接收通知。页面左侧为触发记录，右侧为规则列表/编辑区。

## 监控类型

| 类型 | 监控对象 | 典型用途 |
| --- | --- | --- |
| 策略监控 | 策略结果与交易信号变化 | 当日入选/调出提醒 |
| 个股信号 | 信号库中的技术或自定义信号 | 指标金叉、自定义条件触发 |
| 价格/涨跌 | 价格、涨跌幅、上穿/下穿 | 点位与幅度提醒 |
| 市场异动 | 涨跌停、连板等市场状态 | 情绪与梯队监控 |
| 板块监控 | 指数、概念、行业 | 板块涨跌幅与分钟异动 |

## 创建规则

1. 新增规则，选择类型与分类。
2. 选择作用范围（指定标的 / 策略结果 / 全市场）。
3. 添加一个或多个条件，选择 **AND**（全部成立）或 **OR**（任一成立）。
4. 设置冷却期、严重级别与提示内容，保存并启用。

## 触发记录与通知

- 记录支持筛选与清空；清空只删历史，不删规则。
- 通知渠道：页面弹窗、声效、语音播报、飞书 Webhook、企业微信 Webhook / 智能机器人长连接。页面类在「设置 → 系统设置」配置，Webhook 在「设置 → 实时监控」配置。
- 推送内容直接展示业务标题与正文，内部类型会转成可读描述（如连板/梯队）。

::: warning 全市场规则的开销
全市场规则计算范围大，创建前确认数据权限与刷新频率；冷却期用于避免同一条件持续成立时重复通知，测试时可临时缩短，正式使用应恢复合理值。监控规则按账号隔离，触发记录只投递给规则所属账号。
:::
