# 回测

**用途**：把策略信号转换为持仓与成交，评估完整交易过程。页面含「策略回测」与「验证」（参数优化、步进优化）两个视图；因子检验在「因子」页完成。

## 基础配置

- 策略与资产类型、股票池、起止日期、基础过滤条件、策略参数。
- 开始前确认回测区间内的日 K、除权因子、Enriched 数据完整，否则结果只反映已有数据。

## 成交时序

| 口径 | 含义 | 适用 |
| --- | --- | --- |
| 当日收盘 | 信号确认当日以收盘价成交 | 日线信号，假设尾盘可成交 |
| 次日开盘 | 信号次日以开盘价成交 | 最常用的保守口径，避免未来函数 |
| 下一分钟开盘 | 信号在当前分钟确认后，用下一根分钟 K 的开盘价成交 | 需要分钟数据能力与完整分钟 K |

## 交易约束

支持 A 股 T+1、佣金、印花税、滑点、最大持仓数量、总敞口、仓位分配方式、止损规则、最大持有期。费用与滑点参数与模拟盘同名同默认值，便于两端口径对齐。

## 结果解读

- **净值曲线与回撤曲线**：观察收益路径与最大回撤发生的时点。
- **收益类**：总收益、年化收益、基准收益、超额收益。
- **风险类**：最大回撤、夏普、索提诺、Calmar、蒙卡回撤（中位 / 95% 边界）。
- **交易类**：成交笔数、胜率、盈亏比、平均盈亏、平均持仓天数、最好/最差单笔。
- **因子归因**：策略评分引用因子时，对比盈利单与亏损单的因子均值。

## 参数优化与步进优化（Beta）

- **参数优化**：在指定范围搜索参数组合，任务由独立 worker 执行，可取消并恢复状态。组合数随维度快速增长，应从少量参数、小范围开始。
- **步进优化（Walk-Forward）**：按「训练天数 / 测试天数 / 步进天数」滚动，每折在训练区间选参、在相邻测试区间验证。重点看样本外复利、IS→OOS 退化、参数与收益方向一致性、有效折数。区间不足以覆盖训练+测试窗口时任务会失败，应延长区间或缩短窗口。

::: danger 避免过拟合
历史区间最优参数不等于未来最优参数。参数优化结果必须结合样本外验证（步进优化）、参数稳定性与实际交易成本共同判断；单一区间的漂亮曲线不构成策略有效性的证据。
:::
