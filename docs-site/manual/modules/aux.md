# 辅助页面速览

以下页面作为主业务线的补充视图，按需使用，不影响策略与回测口径。

| 页面 | 路径 | 用途与要点 |
| --- | --- | --- |
| 异动监控 | `/abnormal` | 聚合集合竞价、盘中异动与区间偏移，支持按阈值筛选、信号扫描与竞价基准对比；盘中数据依赖实时行情，权限与轮询间隔决定刷新频率。 |
| 公司图谱 | `/company/graph` | 维护重点公司清单，按「公司 / 人 / 消息」三层展开关系与线索，适合做基本面与事件跟踪。 |
| 公告 / 新闻 / 快讯 | `/info/announcements` 等 | 公开信息聚合与检索：公告全文、新闻流与实时快讯，可用于事件驱动研究的素材收集。 |
| 市场环境 | `/regime` | 每日市场状态（Regime）的时序趋势与状态分布，支持 1 年 / 2 年 / 自定义区间回看，用于判断系统性环境而非个股选择。 |
| 三年五倍 | `/growth` | 扫描滚动窗口内「谷底最低价 → 之后最高价」涨幅 ≥5 倍的标的，窗口不超过 756 个交易日，按倍数/涨幅/峰值日排序，右侧 K 线复现区间便于人工复核。 |

## 使用建议

- 异动与快讯属于盘中信息流，适合发现线索；是否值得跟进，仍应回到因子检验与回测验证。
- 公司图谱的消息层会标注来源，二手信息应回到公告原文核对。
- 三年五倍是**事后统计**：命中标的由未来高点回看确定，不能用于当日选股，只适合研究长期上涨的共同特征。

::: warning 避免误用
市场环境、异动、快讯与图谱类页面输出的是状态与线索，不含买卖建议；把它们直接当作交易信号会引入前视偏差或情绪化决策。
:::
