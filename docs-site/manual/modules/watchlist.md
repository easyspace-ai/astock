# 自选

**用途**：维护个人关注标的，快速查看行情、日 K、分时与自定义指标列。

## 操作要点

1. **添加标的**：搜索框输入代码或名称（支持 `000001`、`000001.SZ`、中文简称），从结果中选择添加；也可用截图 OCR 批量识别后确认导入。
2. **视图切换**：表格视图适合排序对比，卡片视图适合单标的速览；列配置可选择基础指标、日 K 指标或分时指标。
3. **筛选与排序**：按板块、数值条件过滤；多条件叠加时结果为空，应先减少条件再排查。
4. **列表管理**：置顶、移除、清空。清空为批量删除，需二次确认，不影响行情数据与策略数据。

::: warning 实时与分时限制
免费能力下仅自选前 5 个标的进入实时刷新范围；分时列通常需要分钟级数据能力。拥有分钟权限不代表页面自动刷新，还需在「设置 → 实时监控」开启对应开关。
:::

自选列表按账号隔离：每个账号只看到自己的自选，互不影响。
