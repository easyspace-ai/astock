# 策略

**用途**：运行选股策略，查看指定交易日的候选标的、评分与命中原因，并管理策略参数。

## 页面结构

- 顶部切换**股票 / ETF**，两类策略池相互独立，切换后数据范围、可用策略与结果都会变化。
- 策略列表先加载摘要，点击卡片再按需加载明细，减少进入页面的等待。
- 选择「全部」可看多策略合并结果；同一标的被多个策略命中时应结合策略名与评分判断，而非当成单一策略结论。

## 常用操作

1. 点击卡片查看结果，切换交易日期查看历史结果。
2. 调整**基础参数**（市值、价格、交易状态等通用过滤）或**策略参数**（阈值、窗口、信号参数）后重新运行。
3. 结果区可按评分或字段排序、筛选、调整列、加入自选。
4. 开启/关闭该策略的监控；监控开关只影响监控行为，不改变策略结果。

## 创建策略

- **AI 创建**：描述目标（适用资产、条件、评分方向、可调参数、所需字段），由 AI 生成符合规范的策略草稿。
- **自定义代码**：按模板编写逻辑、参数、评分与元数据。
- 内置策略受保护，页面删除只作用于用户策略文件；删除前确认策略未被监控规则、回测配置引用。

::: tip 评分口径
评分是策略定义的一部分。自定义评分字段若未落表，会在执行时基于可用字段临时计算；评分整列为空时，先检查表达式引用字段是否存在、字段名是否拼写正确、当日数据是否完整。
:::
