# 财务分析

**用途**：查看核心财务指标与三大报表，并基于财务数据做筛选与研究。

- **数据内容**：核心指标、利润表、资产负债表、现金流量表、股本及历史股本。财务数据依赖对应数据服务能力。
- **披露口径**：财报期、公告日、交易日含义不同。系统按公告日口径提供点时字段（`pit`），避免用尚未公告的数据推断更早交易日。
- **历史股本与换手率**：当日优先使用最新维表股本；历史日期优先使用当时可用的历史股本，缺失时回退最新维表。财务与历史股本同步完成后，可按 Enriched 批次重算历史换手率。
- **AI 财务分析**：可生成财务报告、关注点与风险摘要，支持复制、最小化、历史查看与重新生成；本地最多保留 20 条相关历史，需要长期保存的内容应及时导出。
