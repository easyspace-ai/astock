# 模拟盘与持仓

**用途**：用虚拟资金验证策略与执行规则，观察净值、持仓与成交是否符合预期。

## 账户视图

- **对比视图（默认）**：全账户按收益降序排列，同本金、同费率口径；盘中快照就绪时显示实时估算（带「估」标记），并可叠加归一化净值。
- **账户展开**：总览、净值、持仓、订单（全状态）、成交台账（可导出 CSV）、回合明细（FIFO）、下单、跟单规则、费用、冻结与删除。
- **批量创建**：一次构造一批同规格账户，每个账户可绑定一条跟单规则。

## 下单与结算

- 订单类型：即时（盘中按最新快照价成交）、次日开盘、当日收盘。ETF 即时单自动转次日开盘。
- 遵循 A 股 T+1：当日买入不可卖出，卖出时页面提示可卖数量。
- 定版字段按交易日收盘结算；盘中显示为实时估算，口径与总览一致。
- 费用与滑点参数与回测引擎同名同默认值，便于与回测结果对比。

## 跟单规则

可跟「策略」或「监控规则」：跟策略为双向自动（入场买入、出场全平）；跟监控规则可选择方向。策略/规则触发信号后按规则参数自动下单，无需人工干预。

::: tip 与回测的关系
模拟盘账户可在策略页保存「回测候选」后，与回测同口径对比（累计、年化、回撤、胜率等）。模拟盘是执行层验证，不改变回测的历史统计结论。模拟盘账户与成交记录按账号隔离。
:::
