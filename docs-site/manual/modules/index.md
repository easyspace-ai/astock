# 指数

**用途**：管理指数列表、查看指数日 K 与分时行情。

1. 首次使用依次执行：同步指数列表 → 同步指数日 K。
2. 搜索并选择指数，设置日期范围查看日 K；具备分钟能力时可查看联动分时。
3. 指数数据与股票策略数据链路隔离，不会混入股票策略范围。

## 与回测的关系

回测的基准收益取自指数数据，因此回测前应确认所选基准指数在区间内有完整日 K；基准缺失时超额收益（`excess`）会失真甚至为空。

::: tip 权限差异
指数分时通常需要分钟级数据能力；无该权限时日 K 功能仍可独立使用，页面会给出能力提示。
:::
