# 数据管理

**用途**：系统的数据管理中心。策略、回测、分析出现异常时，先在此确认数据状态。

## 数据画像

卡片覆盖标的维表、日 K、除权因子、Enriched、指数、ETF、分钟 K、财务与历史股本、扩展数据，展示数据量、日期范围、更新时间与任务状态。「有数据」不等于所有交易日完整，应结合起止日期判断。

## 常用操作

| 操作 | 作用 | 注意 |
| --- | --- | --- |
| 立即同步 | 按当前配置更新 A 股 / 指数 / ETF 数据 | 关闭页面一般不会立即停止后端任务；任务进行中不要清数据或重启 |
| 修正数据 | 重新获取或修复指定范围的异常数据 | 先缩小日期与标的范围；全量修正耗时长、调用量大 |
| 扩展历史 | 把本地日 K 向更早日期扩展 | 受数据源权限与服务端历史覆盖范围限制 |
| Enriched 重算 | 重算指标、信号与扩展字段 | 覆盖对应范围结果，不删原始日 K；按批次计算避免一次全量 |
| 财务换手率重算 | 按批次重算历史换手率 | 需先完成财务与历史股本同步 |
| 分钟 K 设置 | 配置分钟数据标的池、区间与周期 | 开启日内监控不会自动补齐历史分钟 K |
| 测试端点 | 验证数据源地址、鉴权、字段映射 | 样例成功不代表分页、限流与历史范围可用 |
| 清除数据 | 重新初始化本地数据 | **高风险**：影响所有策略与分析，务必先备份 |

::: danger 清除数据前必须
① 备份整个 `data/` 目录；② 确认没有同步、回测、重算任务运行；③ 明确清除范围；④ 预留重新同步时间。清除动作不可撤销。
:::
