# 因子

**用途**：因子的检验、管理、编写、组合与挖掘，是研究线的主入口。页面含五个标签页：检验、因子库、编辑器、组合、挖掘。

## 检验

- 配置：因子、股票/ETF、起止日期、分组数量、加权方式、成本参数。
- 结果：**IC**（因子值与未来收益的截面相关性）、**IC 胜率**（方向符合预期的比例）、**分层收益**（各组收益差异）、**多空表现**（高分组与低分组之差）。
- 统计口径：提供 Newey-West 稳健 t 值与 BH-FDR 多重校正 q 值，批量检验可一次评估多个因子。
- 检验前必须确认因子方向（值越大越好 / 越小越好），它决定排序与多空定义。

## 因子库

- 内置 77 个因子，按动量、波动率、量价、收益形态等分组；自定义与复合因子在库内统一管理。
- 生命周期：**草稿 → 激活 → 观察 → 退役**。编辑器保存为草稿，检验通过后手动激活。
- 修改公式保存为新版本并回到草稿态；只改名称、分组等元数据不影响状态。
- 共享层定义（对全部账号一致）标记为「共享 · 只读」，可直接引用但不能编辑、改状态或归档；账号自建因子仅本人可见可改。

## 编辑器

- 用 DSL 公式编写自定义因子，例如 `rank(-ts_sum(change_pct, 5))`。
- 工作流：写公式 → 校验语法 → 试算 40 日 IC → 保存草稿。
- 算子面板按「时序 / 截面 / 工具」分组，共 25 个算子；可用字段中英双语显示，点击插入光标处。
- 校验错误可定位到出错字符附近；通过后显示依赖列与预热天数（预热不足会让早期样本为空）。

## 组合与挖掘

- **组合**：多个因子按权重合成复合因子，检验口径与单因子一致，与策略评分共用同一条物化路径。
- **挖掘**：嵌套样本外的因子与策略挖掘，含方向重估、相关性剪枝、多因子组合搜索，并保留自有策略作对照轨。候选入库后需显式确认发布，系统不会自动上线。

## 与策略的四个联动入口

| 方向 | 入口 | 效果 |
| --- | --- | --- |
| 策略 → 因子 | 策略触发器编辑里的 Zap 按钮 | 用因子快速创建条件信号，阈值给建议值，自动挂到入场/离场触发器 |
| 因子 → 策略 | 因子库「生成策略」 | 生成单因子排名策略（含入场/离场评分阈值、每日入选上限），保存后可直接回测 |
| AI → 因子 | 自定义信号 AI 生成 | 提示词自动注入全部因子分组，可直接描述因子条件 |
| 回测 → 因子 | 回测结果「因子归因」 | 对比盈利单与亏损单入场日的因子均值，判断该因子的筛选贡献 |
