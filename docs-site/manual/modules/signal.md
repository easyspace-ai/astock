# 信号库与持仓提醒

## 信号库（/signals）

统一管理预计算信号与自定义条件信号，供策略触发器、回测与监控调用。

- **内置信号**：随系统提供，只读，保证规则稳定；如不需要可「隐藏」，只影响自己的列表与选择器，已引用它的策略照常计算，随时可恢复。
- **自定义信号**：由「字段 + 运算符 + 值」组成，启用后生成 `csg_<id>` 信号列（历史迁移信号沿用 `signal_*` 原名）。
- **归档**：可逆，收进「档案库」后不在信号库与选择器出现，但仍参与计算，引用方不受影响。
- **AI 生成**：用自然语言描述条件，系统会把可用字段与因子分组注入提示词。

::: warning 字段频率要匹配
日线字段不能准确替代分钟级触发条件。涉及日内上穿/下穿的条件，应在具备分钟数据的前提下用日内字段表达，否则回测与实盘监控会出现口径偏差。
:::

自定义信号按账号隔离：id 全局唯一，他人定义既不可见也不可改；知道列名仍可能被引用，因此不要对外传播自己的信号 id。

## 持仓提醒（/lots）

按买入批次记录个股/ETF 的成本、数量与日期，系统据此自动生成止盈、止损与到期监控规则，无需在监控中心逐条配置。批次数据按账号独立保存。
