# 看板

**用途**：集中呈现市场摘要、关注标的概览、监控通知与常用分析入口，是每日进入系统的第一屏。

## 操作要点

- 市场摘要区展示主要指数与市场状态；卡片按需加载，进入页面不会一次性拉取全部明细。
- 监控通知点击股票名称或代码，直接打开个股详情对话框；需要管理规则或查看完整触发历史时进入「监控中心」。
- 页面数据来自本地数据库与实时行情服务，非交易时段数据保持不变属正常现象。

## 数据不刷新时的排查顺序

1. 「数据」页当日同步是否已完成（日 K、指数、Enriched 是否更新到最新交易日）。
2. 「设置 → 实时监控」中的实时行情开关是否开启。
3. 当前是否处于交易时段（含午间休市与集合竞价时段差异）。
4. 数据服务能力检测结果是否包含实时行情权限。
