# 个股分析

**用途**：单只股票的行情、关键点位与 AI 研究报告。

- **基础分析**：搜索标的 → 查看日 K、成交量、关键价位 → 按需创建点位提醒（到达、上穿、下穿），创建后到「监控中心」确认规则状态。
- **AI 四维分析**：以本地行情与指标为上下文生成报告；同一交易日已有报告时会提示复用或重新生成，重新生成会产生新的模型调用与费用。
- **历史报告**：支持查看、复制、删除与重新分析。复制失败多为浏览器剪贴板权限限制，系统会自动降级到兼容方式。

## 点位提醒的三种触发

| 类型 | 触发条件 | 适用 |
| --- | --- | --- |
| 到达 | 最新价进入设定价位区间 | 观察关键支撑/压力是否被触及 |
| 上穿 | 由下方穿越到上方（需确认价与阈值） | 突破买点、回补缺口 |
| 下穿 | 由上方穿越到下方 | 跌破止损位、趋势破坏 |
