# 设置、账号与权限

## 设置项

| 菜单 | 主要配置 |
| --- | --- |
| 数据源 / TickFlow | Key 保存与替换、能力重新检测、RPM 与批量限制、检测日志 |
| AI 设置 | 模型服务地址、Key、模型名、温度等参数与连通性测试 |
| 实时监控 | 实时行情开关、轮询间隔、飞书/企业微信 Webhook |
| 通知与声效 | 页面弹窗、通知声效、语音播报与语音包 |
| 扩展页面 / 菜单设置 | 页面显隐、菜单分组与顺序 |
| 系统设置 | 自动运行策略、盘前/盘后任务时间、前端缓存刷新 |
| 配置备份 | 按类别导出/导入配置（策略、调参、信号、因子、自选、监控规则等） |
| 开放接口 | API Token 创建与吊销、权限 scope 勾选 |
| 用户与权限 | 账号新增、密码重置、角色与权限组 |

## 配置备份

备份按类别导出：策略源码、策略调参、策略库与策略池、自定义信号、自定义因子、仓位策略、监控规则、自选、批量持仓、模拟盘、挖掘候选、自定义数据源、分析菜单、扩展页面等。账号私有数据按账号目录单独归档，恢复时落回同一账号。

::: warning 密钥类不默认导出
密钥类配置默认不进入导出包，需单独另行备份。导入前建议先在测试环境验证，避免覆盖现有配置。
:::

## 开放接口

外部程序可凭 API Token 调用读取、写入与任务接口，无需使用面板密码。Token 明文只在创建时显示一次，服务端仅保存哈希；按需勾选最小权限 scope，可随时吊销且立即生效。

## 账号与私有数据隔离

| 数据类别 | 范围 | 说明 |
| --- | --- | --- |
| 行情、指标、Enriched、指数、财务 | 全站共享 | 同一部署内所有账号看到同一份数据 |
| 内置策略、内置因子、内置信号 | 全站共享、只读 | 不可编辑；内置信号可个人隐藏 |
| 自选、持仓批次、模拟盘账户 | 账号私有 | 仅本人可见可改 |
| 策略池、策略调参、自定义策略 | 账号私有 | 他人不可见、不可改；id 冲突返回冲突提示 |
| 自定义信号、自定义因子 | 账号私有 | id 全局唯一，他人不可见不可改 |
| 监控规则与触发记录 | 账号私有 | 通知只推送给规则所属账号 |
| AI 会话、分析报告 | 账号私有 | 按账号目录保存 |
