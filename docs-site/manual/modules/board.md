# 概念与行业

**用途**：观察板块轮动、强弱分布与龙头候选。

## 概念板块

- 首次使用需先获取概念数据；成分股会随数据源更新，不应把旧成分长期视为最新状态。
- 主要视图：涨幅与 RPS 轮动、领涨主线与领跌方向、概念矩阵、概念搜索与成分数量、龙头候选及评分拆解。
- 龙头评分是多项指标的综合结果，应结合成分股走势、流动性与市场环境判断，不可单独作为交易依据。

## 行业板块

- 可切换行业层级，查看最强行业、涨跌行业数量、领涨/领跌行业与行业矩阵。
- 不同层级的行业分类范围不同，横向比较前先确认处于同一层级。

板块等权计算口径：概念与行业按有效成分股等权统计；监控与异动判断要求有效成分不少于 5 只、实时行情覆盖率达到 80%。
