# 连板梯队

**用途**：查看涨停、跌停及其连续状态，判断市场情绪强弱与梯队结构。

- **模式**：涨停模式（涨停、炸板、断板、连板梯队）与跌停模式（跌停、翘板、止跌、连跌梯队），可切换历史交易日回看。
- **卡片信息**：名称代码、涨跌幅、连板/连跌高度、封单量与封单额、概念与行业标签、「一字」标签。
- **涨跌停价**：按市场、板块、ST 状态与当日规则计算，不能简单固定为 10%。
- **盘口修正**：具备五档能力时可用盘口数据修正真假封板；权限不足时以日 K 与实时行情字段判断。
- **板块分布**：点击概念或行业标签查看成分股，再点成分股进入个股详情。
