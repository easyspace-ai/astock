# 常见问题

### 1. 看板/自选数据不更新

按顺序检查：当日同步是否完成 → 实时行情开关是否开启 → 是否处于交易时段 → 数据服务是否具备实时权限。非交易时段数据不变是正常现象。

### 2. 策略结果为空

先确认该交易日日 K 与 Enriched 是否完整，再看基础参数（市值、价格、交易状态）是否过滤过严，最后检查策略所需字段是否存在。字段名拼写错误会让条件恒为假。

### 3. 评分列整列为空

多为评分表达式引用了不存在或尚未计算的字段。检查表达式、依赖列与当日数据完整性；自定义评分未落表时会在执行期临时计算。

### 4. 策略结果数量与回测笔数不一致

两者口径不同：策略结果只表示当日被选中，回测还叠加成交时序、资金、持仓上限、T+1、费用、止损与卖出规则。差异属正常现象，不代表两套逻辑。

### 5. 参数优化/步进优化任务失败

常见原因：回测区间不足以覆盖训练+测试窗口、参数组合过多、区间数据缺失。缩短窗口、减少参数维度或延长区间后重试。

### 6. 监控规则不触发

确认规则已启用、作用范围包含该标的、冷却期未屏蔽、通知渠道已配置；日内类信号还需分钟数据与实时监听开启。全市场规则计算量大，触发存在轮询延迟。

### 7. AI 调用报错或超时

先在「设置 → AI 设置」测试连接，确认地址、Key、模型名与网络可达；长报告超时可缩短提示或改用更快模型。错误信息会显示在页面提示中。

### 8. 页面样式错乱/功能异常

执行「设置 → 系统设置 → 刷新前端缓存」，并强制刷新浏览器（Ctrl/Cmd+Shift+R）。仍异常时确认当前版本与服务端一致。

### 9. 忘记密码

已配置邮件服务可在登录页自助重置；否则由管理员在「管理后台 → 用户与权限」重置。唯一超级管理员无法登录时，需由运维在备份 `data/` 后按流程处理。

### 10. 换机器/迁移

停止服务 → 备份 `data/` 与 `.env` → 新机器部署同版本 → 还原文件 → 启动 → 重新检测数据源与 AI → 抽查自选、策略、监控与数据范围。

### 11. 看不到同事的自选/策略

这是设计上的账号隔离，不是权限故障。需要共享时使用「配置备份 / 资源包」显式导出导入，或由管理员统一维护共享策略。

### 12. 自定义信号想恢复内置的

内置信号从未被修改，隐藏只是本地视图：在信号库底部「已隐藏 · 仍参与计算」区点击「恢复」即可，已引用它的策略全程不受影响。
