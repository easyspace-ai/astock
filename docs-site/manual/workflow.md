# 每日使用流程

## 首次配置（交付后一次）

1. 登录系统，修改初始密码，按团队需要创建账号并分配角色。
2. 进入「设置 → 数据源」，保存数据服务 Key 并执行「重新检测」，确认能力项（日 K / 实时 / 分钟 / 财务）。
3. 进入「数据」，依次同步：标的维表 → 日 K → 除权因子 → 指数 →（按需）ETF、分钟 K、财务数据。
4. 日 K 同步完成后执行一次 Enriched 重算，策略与因子依赖的指标列才可用。
5. 进入「设置 → AI 设置」，填写模型服务并「测试连接」；如需推送，配置飞书 / 企业微信 Webhook。
6. 在「自选」中加入关注标的，在「策略」中挑选或创建策略并试跑一天。

## 盘前（09:00–09:25）

- 确认「数据」页的日 K、指数、Enriched 状态为最新交易日。
- 打开「看板」查看市场摘要与前一日监控通知。
- 在「策略」页运行当日策略，确认候选数量与评分分布是否正常。
- 检查「监控中心」规则为启用状态，冷却期设置合理。

## 盘中（09:30–15:00）

- 「设置 → 实时监控」保持开启时，自选、监控、异动页按轮询间隔刷新。
- 触发通知会以页面弹窗、声效、语音或 Webhook 形式送达；重复触发受冷却期约束。
- 盘中**不执行**数据清理、全量重算、服务重启与版本发布。

## 盘后（15:30 之后）

- 在「数据」页执行当日同步；同步完成后再做 Enriched 重算。
- 运行「复盘」生成当日总结；如配置定时任务，确认推送是否成功。
- 对当日策略结果做归因：查看因子 IC、分层收益与因子归因标签页。
- 对需要验证的假设，在「回测」中跑区间回测或步进优化。

::: tip 节奏建议
数据同步与重算是所有分析的前提：**先数据、后策略、再回测**。当天数据未同步完整时运行的策略结果只代表已有数据，不宜作为决策依据。
:::
