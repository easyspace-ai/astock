# 注意事项

以下条目为使用与运维中的硬约束，建议在交付培训中逐条确认。违反其中数据类与运维类约束，可能直接导致结果失真或数据损坏。

## 1. 数据口径

- **复权**：策略、因子、回测统一使用**前复权**价（`open/high/low/close`）；涨跌停判定使用**不复权**的 `raw_close` 与交易所判定价 `limit_up_price / limit_down_price`。不能用前复权价判断封板。
- **单位不统一**：`change_pct`、`momentum_*`、`deviate_*` 为**小数**（0.05 = 5%），而 `turnover_rate` 为**百分数**（3.5 = 3.5%）。混用是最常见的口径错误。
- **成交量与额**：`volume` 单位为手，`amount` 单位为元。
- **点时数据**：财务字段标注「点时」表示按公告日口径，不会把未公告的数据用于更早交易日；做财务因子与筛选时请保留该口径。
- **日期**：所有结果以交易日为准，非交易日不产生新数据；跨节假日后首个交易日的涨跌停价按交易所规则计算。
- **数据完整性**：卡片显示「有数据」不等于区间完整。回测与分析前必须核对起止日期覆盖，缺失交易日会让区间收益与回撤失真。

## 2. 回测与研究结论

- 回测为历史模拟，遵循 T+1、佣金、印花税、滑点与持仓约束，但与真实成交仍存在差异（盘口深度、涨跌停无法成交、停牌等）。
- 参数优化、步进优化与因子挖掘属于研究工具，多轮搜索会放大过拟合风险，必须以样本外结果与稳定性判断。
- 「策略结果」与「回测记录」口径不同：前者是某交易日被选中的标的集合，后者叠加了成交时序、资金、仓位与费用，数量不一致属正常现象。
- 本系统所有输出**不构成投资建议或收益承诺**，实盘决策与风险由使用方承担。

## 3. AI 能力边界

- AI 输出为辅助材料，可能存在事实错误、口径误用或过度推断，必须人工复核后再使用。
- 调用会把上下文（行情、指标、您填写的关注点）发送到所配置的模型服务，属于**数据出域**；涉密或未公开信息请勿提交。
- 每次调用产生模型费用；定时复盘与批量任务应控制频率与数据范围。

## 4. 多账号与数据隔离

- 行情、指标、Enriched、指数、财务为全站共享；自选、持仓批次、模拟盘、策略池、策略调参、自定义信号、自定义因子、监控规则、AI 会话与报告为**账号私有**。
- 内置策略、内置因子、内置信号为共享只读：任何账号（含管理员）都不能修改共享定义；内置信号可按账号隐藏，只影响自己的列表。
- 自定义信号与因子 `id` 全局唯一：与他人重名会返回冲突提示，请使用带业务语义的命名。
- 「A 看不到 B 的数据」是设计口径而非缺陷；管理员也不能通过界面读取他人私有内容。需要跨账号协作时，使用「配置备份 / 资源包」显式导出导入。

## 5. 运维窗口

| 时段 | 允许操作 | 禁止操作 |
| --- | --- | --- |
| 交易日 09:15–15:05 | 查询、策略运行、监控 | 服务重启、版本发布、数据清理、全量重算 |
| 交易日 16:20–16:50 | 只读查询 | **发布与重启**（盘后数据管道密集期） |
| 其余时段 | 同步、重算、发布、备份 | 无（仍建议先备份） |

数据同步、Enriched 重算、回测与挖掘任务运行期间，不要清除数据、不要重启服务；同步类任务通常在后台继续执行，关闭浏览器不会立即中止后端任务。

版本发布前必须保留一份完整备份（代码版本号 + `data/` 归档），异常时先回滚代码与数据目录，再排查原因；不要在未备份的情况下直接覆盖线上数据。

## 6. 备份与恢复

- 必须备份：整个 `data/` 目录（含 `user_data/` 下各账号私有目录）与 `.env`（含密钥）。
- 建议频率：每次升级前、清除/全量重算前、更换数据源前、迁移服务器前；日常按日或周定期备份。
- 恢复：停止服务 → 还原 `data/` 与 `.env` → 启动 → 重新检测数据源与 AI 连接 → 抽查自选、策略、监控与数据范围。
- 备份文件包含账号数据与密钥，应按内部敏感数据管理，不得外发。

## 7. 安全

- 交付后立即修改初始密码；按最小权限分配角色，离职及时停用账号。
- 公网访问建议置于 HTTPS 反向代理之后，并配合 IP 白名单或 VPN；不要长期直接暴露 `3018` 明文端口。
- API Token 明文只显示一次，服务端仅存哈希；按需勾选最小 scope，泄露后立即吊销。
- `.env`、备份包、Token 不得进入代码仓库或聊天工具。

## 8. 性能与容量建议

- 全市场日 K 同步与 Enriched 重算属于分钟级到小时级的任务，应按批次执行，避免一次加载全部标的导致内存与耗时陡增。
- 分钟 K 数据量远大于日线，只对确需盘中监控或分钟回测的标的池开启，并明确区间与周期。
- 策略页的「自动运行」在策略数量多时会明显增加进入页面的压力，建议关闭后按需点击运行。
- 参数优化、步进优化与因子挖掘为后台任务，同时并发过多会互相抢占算力；建议排队执行并观察任务状态。
- 多账号并发使用时，行情与指标为共享计算，账号数增加主要影响私有数据的读写与列表聚合，不影响行情口径。

## 9. 合规与数据来源

- 行情与财务数据的使用范围受数据服务商条款约束，二次分发、对外提供数据接口前须确认授权。
- 系统仅提供研究与分析工具能力，不代客理财、不提供交易通道、不承诺收益。
- 涉及个人信息的账号数据应遵守《个人信息保护法》等适用法规，仅用于本系统运营目的。
